🌸 TaskFlow – Smart To-Do Manager

A modern and responsive To-Do Web App built using HTML, CSS, and Vanilla JavaScript. It helps users organize, prioritize, and manage their daily tasks efficiently.

✨ Features

- Add, edit, and delete tasks
- Mark tasks as completed
- High, Medium, and Low priority
- Work, Personal, Shopping, and Study categories
- Filter tasks by category
- Light and dark mode toggle
- Tasks saved using Local Storage
- Task date and time tracking
- Responsive design for mobile and desktop
- Clean and modern user interface

🛠️ Technologies Used

- HTML5 – Page structure and content
- CSS3 – Styling, responsive layout, dark mode, and animations
- JavaScript – Task management, filtering, editing, and Local Storage
- Google Fonts – Playfair Display and DM Sans

▶️ How to Run

1. Open the project folder in VS Code.
2. Make sure "index.html", "style.css", and "script.js" are in the same folder.
3. Open "index.html" in a web browser.
4. Start adding and managing your tasks.

No additional libraries or installations are required.
