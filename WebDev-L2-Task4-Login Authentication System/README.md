🔐 SecureGate – Login Authentication System

A modern and responsive client-side authentication system designed to provide a simple and secure login experience. Users can create an account, login using their username or email, and access a protected dashboard.

✨ Features

- User Registration and Login
- Login using Username or Email
- Password visibility toggle
- Password validation with 8+ characters and 1 number
- Password stored in hashed form
- Protected Dashboard after successful login
- Logout functionality
- LocalStorage for user and session management
- Responsive design for different screen sizes
- Clean and modern user interface

🛠️ Technologies Used

- HTML5 – Structure, forms and page content
- CSS3 – Styling, responsive layout, gradients and animations
- JavaScript – Authentication, validation, password handling and dashboard functionality
- LocalStorage – Stores registered users and login sessions

▶️ How to Run

1. Open the project folder in VS Code.
2. Make sure index.html, dashboard.html and style.css are in the same folder.
3. Open index.html in a web browser.
4. Click on Register and create a new account.
5. Login using the registered username/email and password.
6. After successful authentication, the protected dashboard will open.
7. Click Logout to end the current session.

No additional libraries or installations are required.
