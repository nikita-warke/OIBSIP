🧮 NeoCalc – Modern Calculator

NeoCalc is a modern and responsive calculator built using HTML, CSS, and Vanilla JavaScript. It has a clean dark UI and supports basic arithmetic operations with keyboard input.

✨ Features

- Addition, subtraction, multiplication, and division
- Percentage and decimal support
- Clear and Backspace buttons
- Keyboard support
- Operator and decimal validation
- Division-by-zero error handling
- Custom calculation logic without "eval()"
- Responsive design
- Modern glass-style UI

🛠️ Technologies Used

- HTML5 – Structure
- CSS3 – Styling and responsive design
- JavaScript – Calculator logic and functionality

▶️ How to Run

1. Open the project folder in VS Code.
2. Open "index.html" in a web browser.
3. Start using the calculator.

No additional libraries or installations are required.
