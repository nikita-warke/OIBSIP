🌸 Savitribai Phule – Tribute Page

A responsive tribute page dedicated to Savitribai Phule, highlighting her contribution to education, social reform, equality, and humanitarian work.

✨ Features

- Responsive modern design
- Light and dark theme toggle
- Savitribai Phule's story and contribution
- Interactive Before → After legacy section
- Historical timeline
- Achievements section
- Inspirational quote section
- Horizontal draggable timeline
- Keyboard shortcut ("D") for theme switching
- Smooth scrolling and hover animations

🛠️ Technologies Used

- HTML5 – Page structure and content
- CSS3 – Styling, responsive layout, animations, and themes
- JavaScript – Theme toggle, legacy interaction, timeline dragging, and keyboard controls
- Google Fonts – Playfair Display and DM Sans

▶️ How to Run

1. Open the project folder in VS Code.
2. Make sure all files and the "images" folder are in the correct location.
3. Open "index.html" in a web browser.
4. Explore the tribute page and its interactive features.

No additional libraries or installations are required.
